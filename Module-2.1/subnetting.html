Subnetting made easy, using a magic table.

The static table is the reference sheet you already use. The two tools below do the arithmetic for it — hand it a list of departments and a base network and get the full VLSM allocation back, or decode any address/prefix you're handed.

The magic table

Subnetting a /24 by borrowing bits from the last octet — /24 included as the unsubnetted starting point.

/24/25/26/27/28/29/30/31/32
Subnet mask0128192224240248252254255
Block size2561286432168420
# of hosts254126623014620/1 *na
# of subnets1248163264128256

Click any column — or tab to it and press Enter — to see what that subnet size gives you.

/31 and /32 are edge cases, not general host planning. /31 is used only for point-to-point links (RFC 3021) — 2 usable addresses, no network/broadcast reserved. /32 identifies one single address, not a range. If your source shows "0/1" for /31, that may be worth checking against RFC 3021 (2 usable) — easy figure to mistype.
